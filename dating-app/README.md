# HeartLink - Dating App (MVP)

A React + TypeScript Vite app showcasing a dating MVP:
- Email/phone signup/login with mock OTP
- Social login UI (mock)
- Profiles with image upload
- Discovery, likes, matches, chat
- Safety (block/report), moderation, compatibility score, streaks

## Setup

```bash
npm install
npm run dev
```

Open the URL printed by Vite (usually http://localhost:5173).

## Notes
- OTP code for mock flow is always `123456`.
- Data is stored in localStorage.
- Tailwind CSS v4 is used via `@import "tailwindcss"` in `src/index.css`.
